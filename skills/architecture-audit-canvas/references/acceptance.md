# 验收与可复现边界

## 机械检查

先运行 validate_artifacts.py。要求快照未变、引用在范围内、节点/边 ID 不重复、端点有效、聚合路径有中间证据、生成物摘要匹配，且传入模型、交付模型和画布中的模型摘要/内容一致。非法输入应失败，不能静默掉边后输出成功。

## 内容复核

抽查所有高风险结论及关键链路边，确认 refs 真正证明陈述。职责、静态引用、调用、配置、现场事实不混用。未覆盖语言/文件/动态目标明确披露。审核原始模型及最终 HTML/JSON，确保没有凭据、个人/客户数据或无关源码；自动脱敏规则无法保证发现所有秘密。

## 真实浏览器

使用已安装的浏览器工具打开单 HTML。可复用 `scripts/browser_smoke.js`（Playwright CLI run-code 格式），它从数据读取数量，不要求特定项目、端口或节点 ID。先使用本地只读 HTTP 服务或工具支持的 file URL 打开，再执行脚本。

验证缩放、平移、适应、切视图、节点和连线证据、模块/符号下钻、链路前进返回、搜索、风险与问题、窄屏。保存桌面和窄屏截图并实际查看。再阻断全部网络重新载入内嵌文档，确认无网络依赖和脚本错误。截图不能代替真实点击或源码定位验证。

脚本按样例有无相关元素执行对应检查；缺少链路边、函数或风险样例时，要在验收记录明确该功能未覆盖，不能凭少量 true 宣称全部通过。`manifest.browser_verified=false` 是构建时状态；另存浏览器结果，不手工将它改 true 假装生成时已验。

## 技能自身的独立试用

在独立输出目录给评估代理：本技能、真实风格的用户请求、最少原始样例。不给预期答案、已知缺陷或现成模型，让它完成取证到交付。检查是否能按文档调用脚本、是否保持未知边界、生成物是否可用。至少两个不同结构样例；一个真实项目规模扫描可补充性能证据，但不是全仓语义验收。

只有检查实际通过才能说对应范围完成。无法使用浏览器/解释器/现场证据时完成独立部分，并列明未验内容，不自动安装工具、不补造证据。
